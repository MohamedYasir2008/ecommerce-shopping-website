# E‑Commerce Shopping Website

> **Static multi‑vendor e‑commerce demo** – built with **HTML5, CSS3, vanilla JavaScript (ES6+)** and **LocalStorage**. Deploys on **GitHub Pages**.

## Repository
- **GitHub:** https://github.com/MohamedYasir2008/ecommerce-shopping-website
- **Live Demo:** https://MohamedYasir2008.github.io/ecommerce-shopping-website/

## Tech Stack
- HTML5 & semantic markup
- CSS3 with custom properties and utility classes
- Vanilla JavaScript (ES6 modules) – no bundler required
- LocalStorage for data persistence (demo users, products, orders, etc.)
- Chart.js – analytics dashboards for admin & seller
- Font Awesome / Lucide – icons
- Google Fonts – Roboto & Montserrat

## Development Setup
1. **Clone the repository**
   ```bash
   git clone https://github.com/MohamedYasir2008/ecommerce-shopping-website.git
   cd ecommerce-shopping-website
   ```
2. **Open `index.html`** in a browser (no server required). For local testing you can also run a simple static server:
   ```bash
   npx serve .   # or `python -m http.server`
   ```
3. **GitHub Pages** – the `main` branch root is the publishing source. After pushing commits, GitHub Pages will automatically deploy.
